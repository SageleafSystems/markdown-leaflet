# Markdown Leaflet brand assets

The mark is a leaf-shaped sheet split down a glossy fold: raw Markdown on the left (grey source lines and a `#` badge), the rendered page on the right (green blocks with a leaf as its image). It is the app in one picture: write Markdown, read it rendered.

| Asset | Use | Size |
| --- | --- | --- |
| `markdown-leaflet-icon.svg` | Scalable app icon artwork | 1024 × 1024 |
| `markdown-leaflet-icon.png` | Raster app icon source (the `.icns` and Linux icons are made from it) | 1024 × 1024 |
| `markdown-leaflet-logo.{svg,png}` | Horizontal logo for light backgrounds | 1100 × 300 (PNG 2×) |
| `markdown-leaflet-logo-dark.{svg,png}` | Horizontal logo for dark backgrounds | 1100 × 300 (PNG 2×) |
| `markdown-leaflet-logo-stacked.{svg,png}` | Icon over the name, for light backgrounds | 1000 × 1000 (PNG 2×) |
| `markdown-leaflet-logo-stacked-dark.{svg,png}` | Icon over the name, for dark backgrounds | 1000 × 1000 (PNG 2×) |
| `markdown-leaflet-icon-small.svg`, `markdown-leaflet-icon-{16,32}.png` | Simplified icon for 16 and 32 px: no shadow, a bold `#` and simple bars. The macOS `.icns` and Linux hicolor 16/32 px icons use it | 256 × 256 SVG, 16 and 32 px PNG |
| `*.vectorcraft` | Editable VectorCraft source documents | — |

The artwork is free-standing: it has transparent margins and a soft shadow, with no background tile. The lettering is outlined (Avenir Next Bold for "Markdown", Heavy for "Leaflet"), so nothing depends on an installed font. Use the icon alone for launchers and window icons; use a logo where the name can stay readable. Pick the light or dark logo to match the background the name sits on.

Colors: charcoal `#1C1C1F`, off-white `#F6F6F8`, wordmark green `#12A64B` on light and `#30D158` on dark. The mark's leaf and rendered half use a green gradient from `#8BF7AD` through `#2FD66A` to `#079A47`.

Below 48 px the full icon's detail blurs, so use the simplified icon there. Regenerate the PNGs from the `.vectorcraft` files with VectorCraft (export at 2× for the logos, 1× for the 1024 px icon, transparent background).
