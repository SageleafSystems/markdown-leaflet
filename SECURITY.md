# Security policy

This project is preparing its first source release. There is no supported release series yet.

For a suspected vulnerability, use GitHub's **Report a vulnerability** link on the repository's Security tab to send a private report. Include affected versions or commits, reproduction steps, and impact. If private reporting is unavailable, open an issue requesting a private contact route without disclosing the vulnerability details.

Please avoid posting exploit details in a public issue before maintainers have had a chance to review them. Response times are best effort while this is a small project.
